Utafiti Bot

Open-source multi-agent research orchestrator built in TypeScript, framework-free (no LangChain) for full control over orchestration and memory. A typed message bus and an OrchestratorAgent with fan-out/fan-in coordinate specialist agents for web search, data analysis and synthesis. Two-tier memory: token-aware in-session compression plus cross-session persistence, with semantic vector search (Chroma) in progress.

Technologies Used:

  • TypeScript
  • OpenAI API (GPT-4o-mini)
  • Brave Search API
  • lowdb
  • Chroma

Forest Guard

🏆 Grand Prize, Microsoft Student Hackathon 2021 Real-time IoT + ML system for early detection of illegal logging and forest fires, built in one week. Ground-sensor audio is converted into spectrograms and analysed with Azure Cognitive Services to detect chainsaw, machinery and fire signatures, with real-time alerts surfaced through Power BI.
